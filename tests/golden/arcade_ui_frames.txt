# Second Arcade identity list (tools/golden.sh, docs/dev/v080_contract.md A-6, docs/qa-v080.md): menus, the start of a
# stage through GameFlow, the pause menu, the loading picture and the Steam Deck window (1280×800) – everything of
# Arcade the race frames of arcade_frames.txt do not show. Generated from tag v0.7.0 like the race list.
# One run per line:  id | window | shot time (s) | target | arguments (after "--") | mask
#   target  main    the game as the player starts it (res://scenes/main.tscn → GameFlow); --screen=<name> opens a menu
#                   with sample data, --stage=… starts a stage through GameFlow
#           race    the race scene alone (res://scenes/race/race.tscn), as in arcade_frames.txt
#           pause   tests/golden/ui_shots.gd --shot=pause (pause menu over a running stage; shot time unused)
#           loading tests/golden/ui_shots.gd --shot=loading (loading picture as the menus show it; shot time unused)
#   mask    rectangles x,y,w,h (window pixels, ";" between them) painted black before the picture is hashed: what
#           follows the wall clock or the version number, not the game – the ◀▶ arrows of the vehicle and start-time
#           screens pulse with Time.get_ticks_msec(), the title shows config/version (changes with the release)
# Every run: --fixed-fps 60, Xvfb with the window size, its own empty XDG_DATA_HOME, --graphics=arcade (v0.7.0 ignores
# it), no --shot-fast. A picture is one PNG <id>_00.png; the hash is the MD5 of its RGB pixels after the mask.
# The list is frozen together with the hash list: after changing a line run "tools/golden.sh make" again.
#
